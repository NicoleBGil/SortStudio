# JulieBlocks game art

The user supplied these two transparent animations. The puzzle uses optimized
animated WebP versions and a PNG poster for paused or reduced motion. The
other numbers are drawn with CSS. Each puzzle character uses the same
accessible numeric label as the original tile.

process trims transparent margins and downsamples to a maximum side of 144
pixels.
